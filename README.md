# وب‌سایت محمد احسنی

نسخه ۱.۰ یک وب‌سایت فارسی و راست‌چین شامل:
- بازی پازل بلوکی مستقل
- کتابخانه پرامپت‌های هوش مصنوعی
- جست‌وجو، دسته‌بندی و کپی پرامپت‌ها
- طراحی واکنش‌گرا برای موبایل و رایانه

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار می‌توانید کل محتویات این پوشه را در یک مخزن GitHub قرار دهید و از GitHub Pages یا Cloudflare Pages استفاده کنید.

## نکته
این پروژه بدون سرور و بدون کلید API کار می‌کند. رکورد بازی فقط در حافظه محلی مرورگر ذخیره می‌شود.
